# Release gate

No ParkAlert release is authorized.

The credential-free web simulation may be built locally with `--dart-define=DEMO_MODE=true`. Android/iOS packages, Firebase deployments, notification Functions, pilots, and store distribution remain blocked until every owner action in [PROJECT_COMPLETION_REPORT.md](PROJECT_COMPLETION_REPORT.md) has redacted evidence.

Signing keys, platform configuration, and generated Firebase options must remain local and ignored.
